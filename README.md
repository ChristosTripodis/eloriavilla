# Eloria Villa website

Static website for eloriavilla.com (Eloria, Vamos, Crete).

- `index.html` is the whole page (text, styles and scripts).
- `img/` holds the photos, renders and the drone video.
- `CNAME` tells GitHub Pages to serve the site on eloriavilla.com.

To change a photo, replace the file in `img/` with a new one of the same name.
